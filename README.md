# COBOL Image Diff Tool

Upload two sets of COBOL screenshots — **actual output** and **expected
output** — and the tool matches them by filename, highlights the visual
differences (e.g. a small corrected value/typo), and gives you a
downloadable ZIP with the diff images and a report.

## What's included

```
cobol_diff_tool/
├── backend/
│   └── main.py              FastAPI backend (POST /compare -> ZIP)
├── frontend/
│   └── app.py                Streamlit UI (upload + preview + download)
├── sample_data/
│   ├── actual_output/        5 demo images (PROGRAM1.png ... PROGRAM5.png)
│   └── expected_output/      5 matching demo images, each with one small
│                              deliberate difference from its actual pair
├── generate_sample_images.py Script that generated sample_data/ (optional to re-run)
└── requirements.txt
```

## Requirements

- Python 3.10+ (tested against 3.12; should also run on 3.14)
- Packages: `fastapi`, `uvicorn`, `python-multipart`, `pillow`, `streamlit`, `requests`

Install once:

```bash
pip install -r requirements.txt
```

## Run it

Open two terminals from the `cobol_diff_tool/` folder.

**Terminal 1 — backend:**

```bash
uvicorn backend.main:app --reload --port 8000
```

**Terminal 2 — frontend:**

```bash
streamlit run frontend/app.py
```

Streamlit will open in your browser (usually http://localhost:8501). The
backend is expected at `http://localhost:8000` by default — override with
the `BACKEND_URL` environment variable if needed:

```bash
BACKEND_URL=http://localhost:9000 streamlit run frontend/app.py
```

## Try it with the sample data

1. In the Streamlit app, upload all 5 files from `sample_data/actual_output/`
   into the "Actual output images" box.
2. Upload all 5 files from `sample_data/expected_output/` into the
   "Expected output images" box.
3. Click **Compare images**.
4. Preview each matched pair inline, then click **Download results ZIP**.

The ZIP contains, per matched filename:

- `comparison_<name>.png` — actual | expected | differences, side by side
- `diff_highlighted_<name>.png` — the expected image with changed regions
  boxed in red
- `report.json` / `report.txt` — percentage of pixels changed, bounding
  boxes of the changed regions, and which files were unmatched (if any)

## How matching works

Files are paired by **base filename**, case-insensitive and extension-independent:
`PROGRAM1.png` (actual) matches `program1.PNG` or `Program1.jpg` (expected).
Anything left over is reported as unmatched instead of silently dropped.

## Notes

- The diff is pixel/visual based (no OCR or COBOL parsing), so it will
  catch any visible change between the two screenshots — a different
  number, a typo, a flipped word, layout shifts, etc.
- `sample_data/` is demo/test data only, generated by
  `generate_sample_images.py`. Swap in your own real COBOL screenshots for
  actual use.
